# BLENDER_GUIDE.md — 初めての Blender（このプロジェクトでやることだけ）

Blender は機能が多すぎて全部覚えるのは無理。この手順書は
**「旅人のモデルを手で少し直して、リポジトリに戻す」だけ**に絞ってある。

> **まず読んでほしいこと**
> 手で直す前に、**「ここをこうしたい」を言葉で伝えてもらうほうが早いことが多い。**
> 例:「帽子の反りをもう少し強く」「ポンチョの裾をもう少し広げて」「目を大きく」
> → Claude が `tools/blender/build_traveler.py` の数値を変えて 10 秒で作り直せる。git で差分も残る。
>
> Blender で手を入れるのが向いているのは、**言葉で言い表しにくいもの**:
> 布のシワ、くたびれ方、微妙な歪み、「なんとなくここが違う」の調整。

---

## 0. 準備（自宅 PC。外出先の PC には入れないこと）

1. https://www.blender.org/download/ から **Blender 4.2 LTS 以降**をダウンロードして入れる（無料）
   - クラウド側は 4.0.2 だが、.glb でやり取りするので版が違っても問題ない
   - 画面の細かい配置は版によって少し違う。**やることは同じ**なので、名前で探せば見つかる
2. 入れたら、実行ファイルの場所を Claude に伝える（`CLAUDE.md` の「環境メモ」に書き足す）
   - 例: `C:\Program Files\Blender Foundation\Blender 4.2\blender.exe`
3. 最初の起動でスプラッシュが出たら、何もない場所をクリックして閉じる
4. 最初から置いてある立方体・カメラ・ライトは邪魔なので消す
   - `A` キー（全部選ぶ）→ `X` キー →「削除」をクリック

## 1. 画面の動かし方（これだけ覚えれば何とかなる）

| やりたいこと | 操作 |
|---|---|
| ぐるっと回して見る | **マウスの中ボタン（ホイールを押し込む）を押しながら動かす** |
| 平行に動かす | **Shift + 中ボタン**を押しながら動かす |
| 拡大・縮小 | **ホイールを回す** |
| 選んだ物に寄る | `.`（テンキーのピリオド）。テンキーが無ければ `View` → `Frame Selected` |
| 正面から見る | テンキー `1` |
| 右から見る | テンキー `3` |
| 上から見る | テンキー `7` |
| 反対から見る | `Ctrl` + 上のテンキー（`Ctrl+1` で背面） |

**テンキーが無いノート PC の場合**: `Edit` → `Preferences` → `Input` →
`Emulate Numpad` にチェックを入れると、キーボード上段の数字がテンキー代わりになる。

**選択**: 左クリックで選ぶ。`A` で全部選ぶ。`Alt+A` で選択解除。

## 2. モデルを開く

`File` → `Import` → `glTF 2.0 (.glb/.gltf)` を選び、ファイルを指定する。

このプロジェクトで手を入れる候補:

| ファイル | 中身 | 手で直しやすさ |
|---|---|---|
| `game/assets/traveler_outfit.glb` | **ポンチョ + 帽子** | ◎ 一番おすすめ。骨が無いので自由に触れる |
| `game/assets/traveler_body.glb` | 素体（ベスト・半ズボン・ブーツなど） | ○ A ポーズと腕の開きだけ壊さないこと |
| `game/assets/traveler_preview.glb` | 上 2 つを合わせた完成形 | △ 見るだけ用。直しても戻せない |
| `game/assets/traveler_cloth.glb` | 今ゲームが読んでいる仮キャラ（骨・アニメ入り） | ✕ 触らない。骨の重みが壊れる |

> **大事**: 手で直すなら **Mixamo に渡す前**にすること。
> リグ（骨）が入った後に形を変えると、骨の重みがずれて動きが壊れる。

## 3. やりたいこと別の手順

### 3-a. ポンチョに布のシワを入れる（一番やりたいであろう作業）

今のポンチョはつるりとした回転体で、シワが無い。これを彫る。

1. `traveler_outfit.glb` を開き、ポンチョを**左クリックで選ぶ**
2. **面を細かくする**（今のままでは目が粗すぎて彫れない）
   - `Tab` キーで「編集モード」に入る
   - `A` で全部選ぶ
   - **右クリック** → `Subdivide`（細分化）
   - 画面**左下**に小さなパネルが出るので開き、`Number of Cuts` を `2` にする
   - もう一度同じことをすると さらに細かくなる（2 回で十分）
   - `Tab` で編集モードを出る
3. **彫る**
   - 画面**左上**のモード選択（今「オブジェクトモード」と出ている場所）をクリックして
     **「スカルプトモード」** に切り替える
   - 画面**左端**の道具の列（出ていなければ `T` キー）から筆を選ぶ
     - **Draw** … 盛り上げる（`Ctrl` を押しながらだとへこむ）
     - **Crease** … 細い溝を彫る ← **シワはこれ**
     - **Smooth** … ならす（やりすぎたとき。`Shift` を押している間はどの筆でもこれになる）
     - **Grab** … つまんで引っ張る（裾の形をいじるならこれ）
   - **筆の大きさ**: `F` を押してマウスを動かす → クリックで決定
   - **筆の強さ**: `Shift + F` を押してマウスを動かす → クリックで決定
   - テンキー `1` で正面から見て、**上から下へなぞる**とシワが 1 本入る
   - 深すぎたら `Ctrl + Z` で戻す

   コツ: シワは**肩から裾に向かって放射状に**、深さはバラバラに、本数は 6〜10 本くらい。
   全部同じ深さ・同じ間隔にすると機械っぽくなる。

4. `Tab` や左上のモード選択で「オブジェクトモード」に戻す

### 3-b. 大きさ・比率を変える（帽子を高く、裾を広く など）

1. オブジェクトモードで直したい物を左クリック
2. `S` キー → マウスを動かす → 左クリックで決定
   - 高さだけ変えたい → `S` のあと `Z` を押す（`S` `Z` の順）
   - 横幅だけ → `S` のあと `X`
   - 数値で指定 → `S` `Z` と押してから `1.1` と打って `Enter`（1.1 倍）
3. **変えたら必ず** `Ctrl + A` → `Scale`（拡大縮小を確定させる）
   - これを忘れると書き出したときにおかしくなる

### 3-c. 一部だけ動かす（滑らかに）

1. `Tab` で編集モード
2. 動かしたい頂点を左クリックで選ぶ
3. **`O` キー**を押す（「プロポーショナル編集」が入る。画面上部の丸いアイコンが点く）
4. `G` キー → マウスを動かす → **ホイールで影響する範囲を変えられる** → 左クリックで決定
5. もう一度 `O` で切る

### 3-d. 位置を直す（靴底を地面に合わせる など）

1. `N` キーで右側にパネルを出す
2. `Item` タブの `Dimensions`（大きさ）と `Location`（位置）で数値を確認・入力できる
3. **このプロジェクトの決まり**: 靴底が高さ 0、左右と前後の中心が 0
   - Blender では**上が Z**。`Location` の `Z` で上下に動かす

---

## 4. 書き出してリポジトリに戻す

1. 直した物を**左クリックで選ぶ**（複数なら `Shift` を押しながらクリック）
2. `File` → `Export` → `glTF 2.0 (.glb/.gltf)`
3. 右側の設定で:
   - `Format` … **glTF Binary (.glb)**
   - `Include` → `Selected Objects` に**チェックを入れる**
   - `Transform` → `+Y Up` に**チェックが入っていること**（既定で入っている）
4. ファイル名を決めて保存
   - ポンチョ + 帽子を直したなら **`traveler_outfit_edited.glb`**
   - 素体を直したなら **`traveler_body_edited.glb`**
   - （元のファイルを上書きしないこと。比べられなくなる）
5. GitHub の `docs/reference/character/edited/` に Add file → Upload files でアップロード
   - フォルダが無ければ、アップロード画面でファイル名の前に
     `docs/reference/character/edited/` と打つと作られる
6. Claude に「上げた」と伝える。こちらで:
   - 四面図に描いて基準画像と並べる
   - 問題なければ、それを正式なモデルとして扱う（下の「その後の扱い」参照）

## 5. その後の扱い（相談したいこと）

今の `CLAUDE.md` には「Blender の GUI 操作はしない。bpy スクリプトでヘッドレス生成する」と書いてある。
これは**作り直しが効く・git で差分が見える**という利点のための決まり。
手で彫ったモデルが入ると、この前提が変わる。扱い方は 2 つある:

- **A案（スクリプトを正とする）**: 手で直したものを見て、Claude が `build_traveler.py` に同じ形を入れ直す。
  シワのような「規則がある形」なら式で書けることが多い。
  利点: 作り直しが効く。欠点: 完全に同じにはならない
- **B案（手で彫ったものを正とする）**: `traveler_outfit_edited.glb` をリポジトリの正式な素材にして、
  `build_traveler.py` は「素体と、最初のポンチョを作った道具」という位置づけに下げる。
  利点: 彫った形がそのまま残る。欠点: 以後の形の変更は毎回 Blender を開く必要がある

**おすすめは「素体は A 案、ポンチョと帽子は B 案」。**
素体は Mixamo に渡すので機械的に作り直せたほうがよく、
ポンチョは見た目の主役なので手で詰めた形をそのまま残す価値がある。
決まったら `CLAUDE.md` を書き換える。

## 6. よくあるつまずき

| 症状 | 原因と直し方 |
|---|---|
| 何も見えない | ホイールで引く。または `A`（全選択）→ `.`（テンキー）で選んだ物に寄る |
| スカルプトで筆が効かない | 面が粗すぎる。3-a の 2（Subdivide）をやる。または筆の強さが 0（`Shift+F`） |
| 彫った形がカクカク | 細分化が足りない。もう 1 回 Subdivide する |
| 書き出したら向きが倒れている | 書き出し設定の `+Y Up` を確認。それでも倒れていたら Claude 側で直せる |
| 書き出したら大きさがおかしい | `Ctrl + A` → `Scale` を忘れている |
| 色が全部グレーになった | マテリアルが外れた可能性。Claude 側で色を貼り直せるので、そのまま上げてよい |
| 間違えた | `Ctrl + Z`（何回でも戻せる）。最悪、開き直せば元通り |

## 7. 最初の練習（15 分）

いきなり本番を直さず、これを 1 回通してみるのがおすすめ:

1. `traveler_outfit.glb` を開く
2. ポンチョを選んで、編集モードで Subdivide 2 回
3. スカルプトモードの **Crease** で、正面にシワを **1 本だけ**入れる
4. オブジェクトモードに戻して、ポンチョと帽子を両方選んで `traveler_outfit_edited.glb` に書き出す
5. `docs/reference/character/edited/` にアップロードして Claude に伝える

これが通れば、あとは同じことの繰り返し。
Claude 側で四面図にして基準画像と並べるので、**見比べながら少しずつ詰められる**。
