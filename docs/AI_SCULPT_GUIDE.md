# AI_SCULPT_GUIDE.md — AI 3D 生成を「参考彫刻」として 1 回だけ使う手順

## これは何をするものか

イラストから 3D を作る AI サービス（Tripo / Meshy など）で旅人を 1 体生成し、
**ゲームには入れず、形を見比べる材料としてだけ使う。**

狙いは 1 つ。今のモデル（`tools/blender/build_traveler.py` が作る回転体）に足りない
**布のたるみ・シワ・柔らかさ**が、AI の出力ではどう表現されているかを見ること。
それを見てから、bpy スクリプトに形として入れ直す。

### なぜ「参考」に留めるのか（2026-09-18 の判断）

| | 今の bpy スクリプト | AI 生成メッシュ |
|---|---|---|
| 円錐・円筒の鋭いエッジ（つばの反り・ボタンの縁・立ち襟） | **得意** | 溶けて丸まりやすい |
| 布のたるみ・シワ | **苦手**（今は無い） | **得意** |
| ポリゴンの流れ | きれい（揺れの骨を通せる） | ぐちゃぐちゃ |
| Mixamo 自動リグ | 通る（腕を離した A ポーズ） | ポンチョ姿は腕が埋まって通らない |
| 塗り | 単色（ワールドのフォグと馴染む） | テクスチャに陰影が焼き込まれる |
| 直しやすさ | 数値 1 つ変えて 10 秒で再生成、git で差分が見える | 再生成すると別物。手で直すしかない |
| 商用利用 | 制限なし | 無料枠は非商用 or 生成物が公開設定のことが多い |

ゲーム中に見えるのはほぼ「帽子の円錐 + ポンチョの円錐 + 脚とブーツ」なので、
AI が苦手な領域と、この企画で必要な領域が重なっている。
だから**置き換えではなく、足りないところを教えてもらう**使い方にする。

### 権利についての考え方

- 生成物は **ゲームに入れない**（リポジトリには参考として置くが、ビルドには含めない）
- もとの絵はユーザー自身のキャラクターデザイン。生成物はそれを立体にしたもの
- それでも無料プランの規約は変わるので、**使う前に各サービスの最新の規約を確認**すること
- 気になる場合は、生成物をダウンロードせず**画面で見るだけ**でもよい（スクリーンショットを
  リポジトリに置いてくれれば、それだけでも形の参考になる）

---

## 1. サービスに渡す画像（もう用意してある）

4 面図を 1 枚のまま渡すと「4 体並んだ物」や「平たい板」が出てくる。1 面ずつに切ってある:

```
docs/reference/character/ai_input/
  poncho_1_front.png   poncho_2_left.png   poncho_3_back.png   poncho_4_right.png
  body_1_front.png     body_2_left.png     body_3_back.png     body_4_right.png
```

- `poncho_*` … ポンチョ姿（**こちらを優先**。欲しいのは布のシワなので）
- `body_*` … ポンチョ無しの姿（余裕があれば。頭・ブーツ・手袋の形の参考になる）

いずれも白背景・正方形・中央寄せ（サービスが好む形）にしてある。
（作り直すときは `python3 tools/split_turnaround.py <ターンアラウンド.png> <出力先> <名前>`）

## 2. ブラウザでの手順

1. GitHub で `docs/reference/character/ai_input/poncho_1_front.png` を開き、右上の Download で保存
   - 多面入力に対応しているサービスなら `2_left` / `3_back` / `4_right` も保存
2. サービスにアクセスして無料アカウントを作る
   - **Tripo AI** … 画像から 3D。無料枠あり。多面入力とリグ付けの機能もある
   - **Meshy AI** … 画像から 3D。無料枠あり
   - どちらでもよい。**まず 1 つだけ試す**（クレジットを使い切らないため）
3. Image to 3D（画像から 3D）を選び、**まず `poncho_1_front.png` の 1 枚だけ**で生成する
   - 多面入力の欄があれば front / left / back / right に対応する画像を入れる
   - 左右を入れる欄がある場合、**`2_left` がキャラの左**（ブーツのつま先が画面左を向いている面）
   - 「対称（Symmetry）」の選択肢があればオンにする
   - スタイルの選択肢があれば「そのまま / オリジナル」系を選ぶ（リアル化させない）
4. できあがったら **GLB 形式**でダウンロードする
   - GLB が無ければ OBJ か FBX でもよい（こちらで読める）
   - ポリゴン数の選択肢があれば多いほうでよい（参考なので軽さは不要）
5. GitHub の `docs/reference/character/ai_sculpt/` に Add file → Upload files でアップロード
   - ファイル名は `poncho_raw.glb`（ポンチョ姿）/ `body_raw.glb`（ポンチョ無し）にしてもらえると助かる
   - フォルダが無ければ、アップロード画面でファイル名の前に `docs/reference/character/ai_sculpt/` と
     打つと作られる
6. ダウンロードせず画面で見るだけにする場合は、**四方から見たスクリーンショット**を同じ場所に
   アップロードしてくれれば、それでも形の参考になる

## 3. そのあと Claude がやること

```bash
# 1. 大きさと向きを揃える（身長 1.6m、靴底を 0 に、正面を -Z に）
blender --background --python tools/blender/normalize_sculpt.py -- \
  docs/reference/character/ai_sculpt/poncho_raw.glb game/assets/sculpt_ref.glb 1.6 0

# 2. 四面図に描く
bash tools/model-view.sh build/sculpt res://assets/sculpt_ref.glb 1.6

# 3. 基準画像とシルエットの幅を突き合わせる
python3 tools/compare_silhouette.py \
  docs/reference/character/traveler_turnaround_poncho.png build/sculpt_1.png
```

- 向きが横を向いていたら `normalize_sculpt.py` の第 4 引数（角度）で直す（90 / 180 / 270 など）
- そのうえで「AI の形 / 今のモデル / 基準画像」の 3 つを並べた比較画像を作り、
  **今のモデルに足りないところ**を `build_traveler.py` に入れ直す

## 4. 期待できること・できないこと

**期待できる**
- ポンチョのシワ・たるみの入り方（どこに、どの向きに、どのくらいの深さで入るか）
- 帽子のくたびれ方、布の厚みの見え方
- 頭・ブーツ・手袋の立体としての丸み

**期待できない**
- そのままゲームに入る品質（ポリゴンの流れ・リグ・塗りの問題が残る）
- つばの反り・ボタンの縁など、薄く鋭いところの再現（今のモデルのほうが正確なはず）
- 寸法の正しさ（AI は絵の比率を厳密には守らない。**寸法は今までどおり実測値が正**）
