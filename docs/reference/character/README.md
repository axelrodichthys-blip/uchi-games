## 実測した寸法表（2026-09-18）

確定ターンアラウンド 2 枚を画素で測った（`python3 tools/measure_reference.py <画像>`）。
**2 枚は別々に生成したので寸法が完全には揃っていない**が、**目の帯（襟の上〜つばの下）がぴたり一致する**。
そこを重ねて縮尺を決めた:

- ポンチョ姿（全高 = 帽子の先まで 1.60 m）… 襟の上 0.705 → **1.128 m** / つばの下 0.750 → **1.200 m**
- ポンチョ無し … 目 0.795〜0.834 を同じ帯に合わせると全高 **1.429 m** 相当

## モデルの作り方（2026-09-18）

`blender --background --python tools/blender/build_traveler.py` で 4 つ出る:

| 出力 | 使い道 |
|---|---|
| `traveler_body.obj` / `.mtl` | Mixamo にアップロード（ポンチョ・帽子なし） |
| `game/assets/traveler_body.glb` | 素体の確認用 |
| `game/assets/traveler_outfit.glb` | ポンチョ + 帽子。リグの後に `add_outfit.py` で被せる |
| `game/assets/traveler_preview.glb` | 完成形の確認用（ゲームでは読まない） |

見比べるとき: `bash tools/model-view.sh build/full res://assets/traveler_preview.glb 1.6`
→ 正面 / 左 / 背面 / 右 の 4 枚。`python3 tools/sheet.py build/full build/sheet.png` で 1 枚に並ぶ。

### スケッチ・確定画像から変えたところ（形を通すため）
- **腕の開きは 21 度**（一般的な A ポーズの 40 度より浅い）。ポンチョの中に手が収まるようにした
- **羽の突起は短め**。長いと帽子の円錐を突き抜けるため
- **足のつま先 3 本は作っていない**（ブーツに隠れて見えないため）。素足を出す場面ができたら足す
- 頭のてっぺんは **1.30 m**（帽子の円錐の中に入る）。確定画像のポンチョ姿では見えない部分
