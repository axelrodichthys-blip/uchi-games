## 観察メモ（形の特徴。ここを外さない）

> 訂正（2026-09-17）: 当初「手は 4 本指」と書いたが誤り。**素手も手袋も 5 本指**（親指 + 4 本）。
> **足のつま先は 3 本**（ユーザー確認済み）。手と足で本数が違う。スケッチの細部は必ず拡大して数えること。

### 全体のシルエット（01）
- **細長い円錐が 2 つ重なった形**: 上に細長いとんがり帽子、下に裾広がりのポンチョ。その下から細い脚と大きなブーツだけが出ている
- 靴底を 0、帽子の先端を 1.0 としたときの高さの目安:
  - ブーツ 0 〜 0.11 / 見えている脚 0.11 〜 0.21 / ポンチョ 0.21 〜 0.74 / 目の帯 0.74 〜 0.80 / つば 0.80 / 帽子の円錐 0.81 〜 1.0
- 幅の目安（同じく高さ 1.0 に対して）: ポンチョの裾 約 0.42、襟 約 0.18、つば 約 0.21、脚 1 本 約 0.04、ブーツ 1 足 約 0.12
- **腕はポンチョの中に隠れていて外から見えない**（歩き・走りで腕を振らない、という決定と合う）

### 帽子（01）
- 背の高い円錐。先端がわずかに後ろへ傾く（まっすぐな針ではなく、布が少しくたびれた円錐）
- つばは短めで平ら、端が少し反り上がる
- 円錐の前寄りに **丸い継ぎ当て**（ステッチ入り）が 1 つ
- つばの下は頭が真っ黒な帯として見え、そこに **縦長の楕円の白い目が 2 つ**。口や鼻は無い

### ポンチョ（01）
- 肩から裾まで一枚布のテント型。裾は膝下〜すねの中ほど。裾の線は少し波打つ
- 襟は立ち襟気味で顔の下半分を隠す（目だけが襟とつばの間に見える）
- 前は **左胸の大きな丸いボタン 1 つ**で留め、片側の前身頃が上に重なって縦の合わせ目が裾まで通る。それ以外は縫い合わせていない（前が開く構造）
- 肩に小さな折り返し（合わせ目の角）がある

### 脚とブーツ（01 / 02）
- 脚は棒のように細く、真っ黒（身体の色）
- ブーツは脚に対してかなり大きい。筒は折り返しのカフス付き、つま先は丸い。高さは見えている脚と同じくらい

### ポンチョの下（02）
- 頭は縦長の卵型で首は無い（頭がそのまま胴につながる）。頭頂部の後ろに **小さな羽のような突起**
- **短い袖のベスト風の上着**。V 字の襟、前に丸いボタン 3 つ
- 腰にベルト（バックル付き）。**半ズボン**は太もも半ばまでで裾を折り返している
- **腰の後ろ側にベルトで留めた鞄**（柔らかい袋状）
- **手袋**: 丸っこい **5 本指**（親指 + 4 本）。手首にカフス。手袋は明るい色（身体と対比）
- 腕と脚は身体の色（真っ黒）が露出

### 素体（03）
- 頭から胴まで一続きの細身の形。肩幅は狭く、胴はまっすぐ
- 腕は長くて細い。素手は **5 本指**（親指 + 4 本）。指は細長く、人の手と同じ構成
- 脚は長くて細く、膝の出っ張りはほぼ無い。足は丸い塊で、先が **3 本のつま先**に分かれる（獣の足のような丸み。手の 5 本指とは本数が違うので注意）
- 頭身の目安: 頭（頂点〜目の下あたり）を 1 として **約 5 頭身**。脚が全高の約半分
- 目は白い楕円 2 つのみ。口なし

## 3D 化のときの扱い（方針）
- Mixamo に渡すのは **02 の姿（ポンチョ無し、A ポーズ）**。腕・脚がはっきり見えるので自動リグが通る
- ポンチョはリグの後に Blender で被せ、胴の骨 + 布の骨の鎖（`tools/blender/add_cloth_bones.py`）に重みを付ける。腕はポンチョの中に隠れる
- 裾がすねまであるので、歩くと前の脚が布に当たる。SpringBone の当たり（脚のカプセル）で布を押し出す。それでも抜ける場合は裾を少しだけ広げる（形は変えない範囲）
- 頭頂部の突起・帽子の継ぎ当て・ブーツのカフスは **形で作る**（テクスチャにしない）
