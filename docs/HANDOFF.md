## ブラウザで確認できる URL

- **https://axelrodichthys-blip.github.io/uchi-games/** （main に push すると 1〜2 分で自動更新される）
  - 起動すると **「雨の景色」** から始まる。正面の遠くに灯りがあり、飛び石の道と**消えた街灯の列**が続く
  - **灯りに触れると「ネオン」へ移る。** ネオンの道の突き当たりの光るゲートに触れると雨の景色へ戻る

  - コントローラー: 左スティック移動、右スティック視点、LB で走る、A でジャンプ、Start で視点切替

## 今回（2026-09-17）やったこと

### 0. キャラの基準スケッチを受け取った
- ユーザーの手描き 3 枚（完成形 / ポンチョ無し / 素体）を `docs/reference/character/sketches/` に保存し、観察メモ（形・頭身・衣装の構造・3D 化の方針）を同フォルダの `README.md` に書いた。**以後の形と頭身はこれが唯一の基準**
- `docs/REFERENCE_GUIDE.md` の前提表とプロンプトを、スケッチに合わせて「1 画像 = 1 セッション」方式に書き直した（毎回スケッチを添付 + 共通ブロック A / 画像ごとのブロック B / 避けたいもの C）

### 1. ネオンの作り込み
- **路地を 4 本**（大通りから横に伸びる行き止まり）。奥に**自販機の灯り**、上に**吊り電球の列**が並ぶので、大通りを歩いていると「暗がりに点々と灯りが続いている」のが見えて入りたくなる。散らかった箱も置いた
- **看板を「文字らしい形」に**。板 1 枚だったものを、横棒 2〜3 本 + 縦棒 + ときどき囲い（口・国のような形）の組み合わせにして、2〜4 字が縦 / 横に並ぶ看板にした。フォントは持っていない
- **ビルの窓明かり**。真っ黒なシルエットだった建物に輪郭が出た
- **湯気**。マンホール 3 か所と路地の排気口から立ちのぼる
- **通行人の影**。車道の端を黒いシルエットが行き来する（当たり判定なし）。プレイヤーの前後 55m で回しているので、通りのどこを歩いていても何人かいる
- 描画の負荷を抑えるため、看板・窓・電球は色ごとに 1 メッシュへまとめてから置いている

### 2. 雨の景色に「人がいた跡」
- **三角屋根の小屋を 9 軒**（道から 8〜45m の位置。霧の奥にも見える）
- **柵**（腰の高さ。回り込める）と、**消えた街灯を 24m ごと**に道の左右交互に。街灯を点けないのは「点いている灯りは遠くの 1 つだけ」という見つけるものを壊さないため
- 道に近い小屋 2 軒に **軒先の雨どい・吐き口・落ちる水・地面の水たまり**、戸口の脇に **傘立て**
- 雨どいの水は F1 の `rain_amount` で雨と一緒に止まる

### 3. マント（ポンチョ）の揺れ
- `tools/blender/add_cloth_bones.py` を新規作成。Mixamo の .glb に **マントの骨の鎖（胴のまわり 8 方向 × 2 関節 = 16 本）** を後から差し込み、裾に近い頂点ほど元の骨から鎖へ重みを移す
  - 布のうち「胴の骨に付いている頂点」だけを選ぶので、袖・帽子・靴は自然に除ける
  - **Mixamo の自動リグをやり直さなくていい**ので、本キャラに差し替えるときも同じスクリプトを流せばよい
- Godot 側は `traveler_rig.gd` が `SpringBoneSimulator3D` に鎖を登録。アニメの後に掛かるので、歩き出し・止まり・振り向き・ジャンプで裾が遅れて付いてくる
- ゲームが読むモデルは `game/assets/traveler_cloth.glb`（元の `traveler_mixamo.glb` も残してある）

## ユーザーに見てほしいこと・決めてほしいこと

1. **ネオンを歩いて、路地に入ってみる**（大通りの左右、灯りの列が見えるところ）。路地はもっと増やすべきか、奥に何を置きたいか
2. **雨の景色を歩いて、小屋を見る**。小屋の数・大きさ・置き方、街灯を消したままでいいか
3. **マントの揺れの強さ**。F1 の `cloth_stiffness`（小さいほどよく揺れる、今 0.7）、`cloth_drag`（0.35）、`cloth_gravity`（0.3）を動かして、良い数値を教えてください。揺れが邪魔なら `cloth_sway` を「揺らさない」に
4. **スマホの Chrome でもう一度歩く**（前回からの持ち越し）。ボタンの大きさ（`touch_ui_scale`）と軽さ（`render_scale`）。ネオンは光るものが増えたので、重ければ `graphics_quality` を「低」に
5. **ChatGPT でキャラ画像を作る**（スケッチ 3 枚は受け取って `docs/reference/character/sketches/` に保存済み）。`docs/REFERENCE_GUIDE.md` 3 章の手順で、まず **B-1（ポンチョ姿のターンアラウンド）** と **B-3（ポンチョ無し・A ポーズのターンアラウンド）** の 2 枚。出来た画像はチャットに添付するか、GitHub の `docs/reference/character/` にアップロード。その後 Claude がスケッチと画像から bpy でモデルを作り → Mixamo → `mixamo_fbx_to_glb.py` → `add_cloth_bones.py` の順で差し替える
   - **色を決めてほしい**: 帽子・ポンチョ（今はサンドベージュ）、上着・半ズボン、手袋、ブーツ、ボタン・継ぎ当てのアクセント。B-8 のパレット画像で決めてもよい
6. **3 つ目のワールド**をどれにするか（深海 / 夕焼け / 淡い空の空間 / ビル群 / とにかく広い空間）
