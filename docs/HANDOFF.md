## 今回（2026-09-18）やったこと — 本キャラのモデルを組み立てた

### 1. 基準画像を「測って」から作った
確定ターンアラウンド 2 枚は別々に生成したもので、**寸法が揃っていませんでした**（ポンチョ無しのほうが脚も胴も長い）。
そこで `tools/measure_reference.py` を作って画素で測り直したところ、
**目の帯（立ち襟の上〜つばの下）だけは 2 枚でぴたり一致する**ことが分かったので、そこを重ねて縮尺を決めました。

- 見えるシルエット（ブーツ・ポンチョの裾・つば・帽子）→ **ポンチョ姿の画**から
- 中の衣装（ベスト・ベルト・半ズボン・手袋・鞄）→ **ポンチョ無しの画**から

**設計書に最初に書いていた高さ表（つば 1.28m など）は手描きスケッチ基準の目分量で、確定画像とは合っていませんでした。**
実測値に置き換えました（表は `docs/reference/character/README.md`）。主なもの:

| 部位 | 旧（目分量） | 新（実測） |
|---|---|---|
| ブーツの上端 | 0.18 m | **0.216 m** |
| ポンチョの裾 | 0.34 m | **0.365 m** |
| 立ち襟の上 = 目の帯の下 | 1.18 m | **1.128 m** |
| つば = 目の帯の上 | 1.28 m | **1.200 m** |
| 帽子の円錐の根元 | 1.30 m | **1.205 m** |
| 素体（帽子なし）の頭のてっぺん | — | **1.300 m** |

### 2. `tools/blender/build_traveler.py`（新規）でメッシュを組み立てた
1 回流すと 4 つ出ます:

| 出力 | 使い道 |
|---|---|
| `docs/reference/character/traveler_body.obj` | **Mixamo にアップロードするのはこれ**（ポンチョ・帽子なし、A ポーズ） |
| `docs/reference/character/traveler_body_height.txt` | 上の高さ（1.3156 m、羽の突起の先まで）。変換時に渡す |
| `game/assets/traveler_body.glb` | 素体の確認用 |
| `game/assets/traveler_outfit.glb` | ポンチョ + 帽子。リグの後に被せる |
| `game/assets/traveler_preview.glb` | 完成形の確認用（ゲームでは読まない） |

入っているもの: とんがり帽子（後ろへ反る円錐 + 前下がりの反ったつば + 丸ボタン）、
立ち襟のポンチョ（前の重ね合わせ + 胸の丸ボタン + 波打つ裾）、卵型の頭と縦長の目、細い首、
頭頂部の羽の突起、袖なしベスト（折り襟 + ボタン 3 つ）、ベルトとバックル、
折り返しの半ズボン、腰の後ろの鞄、**5 本指**の手袋、カフス付きの大きなブーツ。色は確定パレットのまま。

ポンチョ姿の正面シルエットを基準画像と数値で比べて、**幅のずれは平均 2.3 cm（身長 160cm に対して）**まで詰めました。
その後もう一段、基準画像を観察して詰めた（2026-09-18 後半）: 頭を丸い卵に・目を大きく・ベストを細身に（V を深く、襟を小さく、ベルトが見えるように）・腕を長く（開き 18 度）・羽の突起を見える大きさに・ブーツのカフス・裾の波・つばの反り。

### 3. リグの後にポンチョを被せる仕組み（`tools/blender/add_outfit.py`、新規）
ポンチョはテント型なので Mixamo の自動リグに通しにくい。そこで **Mixamo には素体だけを渡し、
ポンチョと帽子はリグが付いたあとに被せる**方式にしました。
帽子は Head の骨に、ポンチョは高さに応じて Hips / Spine / Spine1 / Spine2 / Neck に重みを配ります
（骨の高さはアーマチュアから読むので、Mixamo が返す大きさが変わっても付いていきます）。
そのあと既存の `add_cloth_bones.py` を流すとマントの揺れの骨が入ります。

### 4. 見比べの道具（`tools/model-view.sh` + `game/tools/model_view.tscn`、新規）
`bash tools/model-view.sh build/full res://assets/traveler_preview.glb 1.6` で .glb を四面（正面 / 左 / 背面 / 右）から描きます。

## 本キャラをゲームに入れました（2026-09-18 後半）

**Mixamo のリグを待たずに、今のモデルで歩けるようにしました。**
既存の仮キャラのリグ（骨 28 本 + アニメ 10 本）を本キャラの寸法に合わせ直して流用しています。

### 通した工程 — `bash tools/build-character.sh` の 1 コマンド
1. メッシュを組み立てる（見た目用: 腕 18 度 / リグ用: 腕 40 度）
2. `retarget_rig.py` … 既存リグを本キャラに合わせ直す
3. `add_outfit.py` … ポンチョと帽子を被せる
4. `add_cloth_bones.py` … マントを揺らす骨 → `game/assets/traveler_cloth.glb`

ゲーム側のコードは**モデルの読み込みに関しては無改造**です（`traveler_cloth.glb` を差し替えるだけ）。

### 途中で分かった大事なこと
- **リグの合わせ方は「一様な拡大 + 上下移動」だけにすること。** 関節を本キャラの位置へ個別に動かしたら、
  右足が 6〜19cm 浮きました。Mixamo のアニメは「休めの姿勢からの回転」で入っているので、
  骨の向きや親からのずれ方を変えると手足の行き先が変わります。
  合わせたのは**股と足首の 2 点だけ**。膝・胸・首・頭は元の比率のまま少しずれますが、ポンチョと帽子に隠れます
- **足の接地判定を実測し直しました**（足音が鳴らなくなったため）。
  `godot --headless --path game res://tools/foot_probe.tscn` で測れます（新しい道具）。
  本キャラの足首は歩きで 0.193〜0.250m。判定値を 0.168/0.186 → **0.208/0.226** に更新
- **ジャンプ中も腕を待機ポーズにしました。** クリップ通りに振るとポンチョから腕が飛び出します。
  「待機・ジャンプでは腕を動かす」は前が開いたコートの頃の決定なので、ポンチョの確定デザインに合わせました。
  F1 の `arm_swing` で「クリップ通り」に戻せます
