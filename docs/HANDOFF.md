# HANDOFF.md — 引き継ぎメモ

最終更新: 2026-09-16（クラウドセッション）

## ブラウザで確認できる URL

- **https://axelrodichthys-blip.github.io/uchi-games/** （main に push すると 1〜2 分で自動更新される）
  - 起動すると **「雨の景色」** から始まる。正面（奥）の遠くに灯りがあり、飛び石の道が続く
  - **灯りに触れると「ネオン」へ移る。** ネオンの道の突き当たりの光るゲートに触れると雨の景色へ戻る
  - **F2** でワールドを順に切替（雨の景色 → ネオン → 灰色の世界（検証用） → 雨の景色）
  - PC の操作: 右ボタンを押しながらマウスで視点（Tab で固定 / 解除）、WASD 移動、Shift で走る、Space でジャンプ、ホイールで距離、V で一人称 / 三人称、F1 で調整パネル
  - コントローラー: 左スティック移動、右スティック視点、LB で走る、A でジャンプ、Start で視点切替
  - **スマホ（Chrome）の操作**: 画面の左半分を指でなぞると仮想スティックが出て移動、右半分をなぞると視点。右下に「ジャンプ」「走る」、右上に「視点」「調整」「ワールド」。タッチ端末では自動で出る
  - 灰色の世界: 右前に 60° の山、左前に台地（30° / 42° の登り坂、50° の下り坂、崖）、右後ろに階段と段差（0.45 / 1.0 / 1.5 / 2.2m）

## 今回（2026-09-16）やったこと

1. **キャラの向き**: Mixamo のモデルは +Z が正面だったので 180° 回して進行方向に合わせた
2. **ジャンプ**: 踏切の大振り・着地の深いしゃがみ・腰の浮きを除去。空中区間をゆっくり再生して滞空全体に使う
3. **足の滑り**: クリップの基準速度の計測を直し、初期値をユーザーの調整値（歩き 3.0 / 走り 6.2）に
4. **腕**: 歩き・走りでは腕を振らない（腕の骨だけ待機ポーズ）。Mixamo クリップの腕のめり込み対策も兼ねる。F1 の arm_swing で元に戻せる
5. **雨の景色**: 灰色の空、フォグ、雨粒、濡れた地面と水たまりの映り込み・波紋、雨音、遠くの灯りと飛び石。F1 で雨の量・水たまりの量と大きさを調整でき、波紋の数は雨の量に連動する
6. **ワールドの土台**（`scenes/worlds/world_base.gd`）: 地形・フォグ・F2 切替・小物ヘルパー・世界の端・フェード・入口（ポータル）・タッチ操作を共通化
7. **段差**: 膝まで（0.5m）は歩いたまま足で、肩〜首まで（1.7m）は前に進み続けるとよじ登る
8. **世界の端**: 端の山並み（登れない斜面）→ 見えない壁 → 落ちたら出現地点に戻す、の三段構え
9. **歩く気持ちよさ**: 足音（アニメの接地に同期）、歩行時のカメラの微かな揺れ、走行時に視野角を少し広げる、ジャンプの先行入力
10. **ネオン（2 つ目のワールド）**: 道の両側のビルと光る看板、濡れた路面に伸びる看板の映り込み、電気のハム、突き当たりの光るゲート
11. **スマホのタッチ操作**: 仮想スティック・ドラッグ視点・ボタン。多点タッチ対応（移動しながら視点とジャンプができる）
