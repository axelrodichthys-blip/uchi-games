# HANDOFF.md — 引き継ぎメモ

最終更新: 2026-09-16（クラウドセッション）

## ブラウザで確認できる URL

- **https://axelrodichthys-blip.github.io/uchi-games/** （main に push すると 1〜2 分で自動更新される）
  - 起動すると **「雨の景色」** から始まる。正面の遠くに灯りがあり、飛び石の道が続く
  - **灯りに触れると「ネオン」へ移る。** ネオンの道の突き当たりの光るゲートに触れると雨の景色へ戻る
  - **F2**（スマホは「ワールド」ボタン）でワールドを順に切替: 雨の景色 → ネオン → 灰色の世界（検証用）
  - PC: 右ボタンを押しながらマウスで視点（Tab で固定 / 解除）、WASD 移動、Shift で走る、Space でジャンプ、ホイールで距離、V で一人称 / 三人称、F1 で調整パネル
  - **スマホ（Chrome）**: 画面の左下側をなぞると仮想スティックが出て移動、右側をなぞると視点、**2 本指でつまむとカメラの距離**。右下に「ジャンプ」「走る（タップで入り切り）」、右上に「視点」「調整」「ワールド」
  - コントローラー: 左スティック移動、右スティック視点、LB で走る、A でジャンプ、Start で視点切替

## 今回（2026-09-16）やったこと

キャラの向き / ジャンプ / 足の滑り / 腕の振りの修正、雨の景色のプロトタイプ、ワールドの土台（`WorldBase`）、段差の乗り越え、世界の端の処理、歩く気持ちよさ（足音・カメラの揺れ・走行時の視野角）、ネオンのワールド、ワールド間の入口、スマホのタッチ操作。

**最後にスマホ（Chrome）の指摘 3 点へ対応:**
1. **ボタンが極端に小さい** → タッチ UI の大きさを px ではなく「画面の短いほうの辺に対する割合」で決めるように変更。ジャンプは短辺の 23%、走るは 16%、上のボタンは高さ 8.5%。F1 の `touch_ui_scale` で全体の大きさを変えられる。HUD の文字も画面に合わせて拡大し、右上のボタンの下に移して重ならないようにした
2. **カクつく** → 画質設定を追加。スマホでは自動で軽くなる（3D の描画解像度 `render_scale` を 0.7 に、影を切る、雨粒を 1440 → 約 420 に、地面のシェーダーの細かいノイズと波紋を省く、アンチエイリアスを切る）。F1 の `graphics_quality`（自動 / 高 / 低）と `render_scale` で手動でも変えられる
3. **ズームの操作が分からない** → **2 本指でつまむとカメラの距離が変わる**ようにした（指を広げると近づく）。走るボタンは押しっぱなしからタップで入り切りに変更
